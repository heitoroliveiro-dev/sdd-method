# Checklist de sessão

## Ao começar (2 min)

- [ ] Li a fase atual (`CLAUDE.md` / `ROADMAP.md`) — sei onde estou
- [ ] Completei: "Hoje eu entrego ______ e sei que terminei quando ______."
- [ ] A tarefa serve ao Norte?
- [ ] Estou na branch certa, atualizada com `main`
- [ ] Se retomando feature SDD: rodei `/speckit-analyze` (e `/speckit-converge` se já há código)
- [ ] Estado da suíte conhecido (verde, ou falhas pré-existentes registradas)

## Ao terminar (2 min)

- [ ] Entendo tudo que foi feito — consigo explicar para outra pessoa
- [ ] Evidência capturada (testes, comando + retorno, screenshot)
- [ ] `tasks.md` com `[X]` refletindo a realidade
- [ ] Se o plano mudou: `research.md`/`plan.md` atualizados
- [ ] Decisão nova virou ADR?
- [ ] Achados fora de escopo registrados no `ROADMAP.md`
- [ ] CHANGELOG atualizado (se houve merge)
- [ ] Fase mudou? `CLAUDE.md` atualizado (curto!)
- [ ] Sei qual é a próxima tarefa
